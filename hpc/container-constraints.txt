# Version pins for the Apptainer image (hpc/path3d.def). Passed to pip with -c.
#
# These are the versions of the core stack the pycoda environment ran on Nibi,
# which is the closest thing to a proven set this project has. Two exceptions,
# each forced by PyPI rather than chosen:
#   opencv-contrib-python-headless  valis-wsi 1.2.0 on PyPI pins ==4.9.0.80.
#                                   pycoda's 4.11 came from the wheelhouse, whose
#                                   valis build had that pin relaxed.
#   torch / torchvision             PyTorch's cu12x indexes stop at different
#                                   releases (cu128 ends at 2.11). 2.14.0 is on
#                                   cu126 and matches the local dev env.
#
# Only packages with a real compatibility story are pinned. The rest is left to
# the resolver and recorded in /opt/path3d/pip-freeze.txt inside the image.
